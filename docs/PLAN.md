# План порта БК-0011М + AZBK на Karabas Go / Mini / Mini G

Источник: [lordamot/retro-tang-bk](https://github.com/lordamot/retro-tang-bk) (`b4b5850`, версия 0.1.28, MIT),
«BK Nano»: БК-0011М с контроллером AZBK (MAXIOL) на Tang Nano 20K (Gowin GW2AR-18C) с платой BL616
рядом. Цель автора: на машине идёт Dangerous Dave in the Haunted Mansion (grf, 2025); на плате Tang это
подтверждено.

## 2. Решения

- **Одна частота 65 МГц** (VCO 650 = 50 x 13): пиксельная частота VESA 1024x768@60 точно (upstream 64.8);
  ВМ1 4.06 МГц (/16), 8.1 в турбо; AY 1.71 МГц (/38). Последовательная частота HDMI 325 МГц и её инверсия
  с того же PLL (не DCM: меньше джиттер, как урок orion128 с 27 МГц).
- **Память: SDRAM 32 MB (16 бит) всех плат.** Пространство AZBK 32 MB ложится на чип один к одному,
  таблица страниц upstream не нужна. Порты и приоритеты арбитра как у upstream (процессор первым, потом
  видео). Пакет видео 4 x 32 бита = 8 чтений по 16 бит подряд (CL2, BL1, 11 тактов против 10-11 у upstream).
  Тактовая чипа = инверсия clk_sys через ODDR2, данные чтения ловятся по спаду. SRAM платы не используется.
- **ПЗУ в файле ядра.** Набор `AZ.INI` upstream ([ROM] слоты 0..56 по 4 KB с адреса 0x40000, логотип
  0x20000) записан в `roms` в `core.json`; прошивка грузит их при каждом старте ядра через ROMLOADER, пока
  машина в сбросе (`mcu_busy`, `rom_active`). Модификации прошивки не нужны.
- **Контроллер AZ без МК.** Всё, что у upstream делал BL616 (`azbk.c`), делает FPGA: чтение / запись
  блока (005/006) идёт в сектор образа F-пункта через `img_sdc.v`; часы (031/042) из RTC платы
  (`rtc_mode` 1, DS1307); EEPROM (021/024) это сектор 0 файла F-пункта «AZ EEPROM»; таблица устройств (011)
  из размеров смонтированных образов; HOF и сеть отвечают как без кабеля; файловые команды по имени
  (047, 050-055) и каталог (003/013), монтирование из программы (004/014) отвечают ошибкой: прошивка
  Karabas не даёт ядру файлов по имени.
- **Устройства AZ0-AZ3 = F-слоты 0-3** (образы `.img/.bkd/.dsk`), `[BOOT] D0` upstream = AZ0.
- **Клавиатура** по таблицам `bk.c` из PS/2 set 2 скан-кодов `kg_mcu`; раскладка та же (F11 сброс,
  F10 СТОП, Alt АР2, правый Ctrl СУ, левый Ctrl РУС, Win ЛАТ). OSD открывается штатно прошивкой.
- **OSD** 512 x 416 в центре 1024 x 768: в `kg_osd_overlay` добавлен `V_DIV4_HEIGHT` (modules PR #25).
- **Видео:** HDMI на Mini / Mini G (zhdmi со звуком 48 кГц), VGA через ЦАП на Go; синхроимпульсы
  отрицательные (VESA).
- **Звук:** PCM5102 (Go, Mini G), сигма-дельта (Mini), HDMI. Громкость из OSD как у upstream.
- **FT_CLK_OUT** 8.125 МГц на Mini / Mini G (правило всех ядер), выходы FDC на Go в 0.

## 3. Этапы

Ветка на этап, один PR в конце этапа (как в orion128).

- **Ф0. Каркас** (сделано): репозиторий, `modules`, импорт RTL upstream, перевод `.sv` в Verilog-2001,
  `bk_system.v`, `bk_sdram.v`, сервис контроллера, клавиатура, загрузчик ПЗУ, тесты верилятором
  (`src/sim/run_bk.sh`: BIOS AZBK за 4 с машинного времени), XST машины отдельно: 58 % LUT, 14 BRAM.
- **Ф1. Mini G**: топ, ucf, сборка, timing (сделано, 26110701: 69 % LUT, 85 % slices; Go и Mini тоже
  собраны, timing выполнен). На плате 2026-11-07: BIOS AZBK проходит, ANDOS 3.30 грузится с AZ0.
  26110702: клавиатура, РУС/ЛАТ, OSD, Display (Color / Grayscale / Mono), звук (все тесты SNDTEST), MEMTEST
  на плате в порядке. Dangerous Dave не проверен (образа нет).
- **Ф2. Go и Mini**: сборка, timing; проверка на платах по возможности.
- **Ф3. Доводка**: запись блоков и EEPROM на плате, джойстик, турбо, ошибки из проверки; README, релиз
  (строка в `cores.json` karabas-go).

## 4. Что проверить на плате (нельзя проверить в симуляции)

- SDRAM на 65 МГц с инвертированной тактовой и SLEW SLOW (как в uknc) на линиях данных: окно чтения
  посчитано в `bk_sdram.v`; если тест памяти (MEMTEST upstream в `SNDTEST.IMG`) даёт ошибки, первым делом
  сдвиг фазы тактовой (PLL CLKOUT вместо ODDR2).
- HDMI 1024x768@60 на 325 МГц через ODDR2.
- Время ответа сервиса на чтение блока (прошивка ~5-15 мс на сектор): ANDOS грузит ~65 блоков.

## 5. Открытые вопросы

- Лицензии: ВМ1 (GPL v2 по upstream) в ядре под GPL-3.0-or-later; ПЗУ AZBK (MAXIOL) и БК (Электроника)
  в `.kg`: допустимо ли в публичном репозитории.
- Часы машины (034) не пишутся в RTC платы (защита от «AltairDOS time prompt», урок orion128).
