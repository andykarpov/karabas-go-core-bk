# Ядро БК-0011М + AZBK для Karabas Go / Mini / Mini G

[English version](README.md)

Домашний компьютер **Электроника БК-0011М** вместе с контроллером **AZBK** (MAXIOL) на платах семейства
Karabas Go (Xilinx Spartan-6 XC6SLX25). Порт ядра [retro-tang-bk](https://github.com/lordamot/retro-tang-bk)
(BK Nano для Tang Nano 20K). Один файл ядра `bk.kg` для всех трёх плат.

Состояние: сборка 26110703. На Mini G проверены BIOS AZBK, ANDOS, клавиатура, режимы экрана, весь звук и
тест памяти; на Go и Mini ядро ещё не запускалось. Что дальше: [docs/BACKLOG.md](docs/BACKLOG.md).

## Машина

**БК-0011М** (Электроника, 1990):

- процессор К1801ВМ1 (PDP-11 без EIS) на 4 МГц, 8 МГц из OSD;
- 128 КБ ОЗУ страницами по 16 КБ, ПЗУ БЕЙСИК и БОС, регистр 177716 (страницы, динамик, СТОП);
- экран БК 512 x 256 (чёрно-белый) или 256 x 256 в 4 цветах, 16 палитр, прокрутка, прерывание 50 Гц;
- клавиатура с РУС / ЛАТ, АР2, СУ, СТОП, кнопкой сброса;
- AY на порту 177714 (так звучит музыка большинства игр БК), динамик.

**AZBK** (контроллер MAXIOL, такой, каким его видит программа):

- диспетчер памяти на **32 МБ**: 16 окон по 4 КБ (177300-177352), трансляция слова 177716 БК-0011М и режимов
  СМК-512 (177130), тени, ПЗУ-страницы;
- собственный экран **1024 x 768, 60 Гц**: 1/2/4/8 бит на точку, до трёх слоёв, растяжение, прокрутка,
  палитра из 256 цветов + наборы старых палитр (177230-177256); экран БК показывается через него;
- **блиттер** (177270/177272): копирование, наложение, заливка, сохранение и восстановление фона;
- звук: **два YM2149** (177172-177175), **Covox** 16 и 8 бит (177200-177212), **звуковой DMA** (PCM 16 бит и
  IMA ADPCM моно / стерео, 44100 Гц), динамик БК;
- **дисковый контроллер** (177220-177226): до четырёх устройств AZ0-AZ3 на образах `.img` / `.bkd` / `.dsk`,
  загрузка с AZ0, прерывание по окончании обмена;
- **EEPROM** настроек (программа Setup), **часы** реального времени (из часов платы);
- **BIOS AZBK** с тестом машины, логотипом, Setup и загрузчиком.

Сети нет: команды сети и «зала славы» отвечают как контроллер без кабеля.

## Платы

| | Karabas Go | Karabas Mini | Karabas Mini G |
|---|---|---|---|
| Видео | VGA 1024 x 768 60 Гц (видео-ЦАП) | HDMI 1024 x 768 60 Гц | HDMI 1024 x 768 60 Гц |
| Звук | I2S ЦАП PCM5102 (линейный выход) | HDMI, аналоговый выход (sigma-delta) | HDMI, I2S ЦАП PCM5102 |
| Память AZBK | SDRAM 32 МБ | SDRAM 32 МБ | SDRAM 32 МБ |
| Клавиатура, джойстик | USB (через МК платы) | USB | USB |
| Образы дисков, EEPROM | SD-карта (SD1) | SD1 | SD1 |
| Часы | RTC платы | RTC платы | RTC платы |

Не используются: SRAM платы, вторая SD-карта, разъём дисковода Go (выходы выключены), магнитофон, UART,
MIDI, FT812 (на Mini / Mini G получает только тактовую).

## Что куда

- **SD-карта (SD1)**, FAT32 или exFAT:
  - `bk.kg` в корень (рядом с другими ядрами);
  - папка `/bk`: образы дисков и `eeprom.dat`. Готовый набор лежит в [sd/bk](sd/bk) этого репозитория:
    скопируйте папку целиком.
- **Монитор**: HDMI (Mini, Mini G) или VGA (Go). Режим 1024 x 768 60 Гц, синхроимпульсы VESA.
- **Звук**: HDMI, разъём наушников / линейный выход платы.
- **USB**: клавиатура, геймпад (через хаб, если нужно оба).
- ПЗУ (AZBOOT, библиотека AZ, ПЗУ контроллера дисков, ПЗУ БК-0011М и БК-0010, Setup, логотип) уже внутри
  `bk.kg`, отдельно класть их не нужно. Прошивка МК обычная, ядро не требует особой версии (поддержка
  формата `.kg`).

## Первый запуск

1. Скопируйте `bk.kg` и папку `sd/bk` на карту, выберите **BK-0011M** в меню загрузки.
2. Машина стартует сама: сначала около 64 коротких писков и сброс (первый проход AZBOOT, так задумано),
   затем синий экран BIOS AZBK с проверкой железа, датой и строкой «Press KT to run Setup»: Esc (КТ)
   открывает Setup.
3. Примерно через 10 секунд грузится ANDOS с AZ0 (`WRKANDOS2.IMG` по умолчанию): заставка, пробел, затем
   двухпанельная оболочка. Программа запускается вводом имени в строке `A>` или Enter на файле.
4. Другой диск: OSD (Menu + Esc), пункт AZ0 (или Menu+F1), образ из `/bk`, затем Reset.

| Пункт | Горячая клавиша | |
|---|---|---|
| AZ0 .. AZ3 | Menu+F1 .. Menu+F4 | образы устройств AZ0-AZ3 (`.img`, `.bkd`, `.dsk` из `/bk`); загрузка с AZ0 |
| AZ EEPROM | | файл настроек контроллера (`/bk/eeprom.dat`, 510 байт); без файла Setup не сохраняется |
| CPU | Menu+C | 4 МГц / 8 МГц |
| Joystick | | геймпад на порту 177714 (вверх 1, вправо 2, вниз 4, влево 10, A 20, огонь 40, огонь 2 100, B 200) |
| Covox 177714 | | старый Covox на 177714: Off (по умолчанию, иначе музыка AY в играх трещит) / AZ setup |

| Display | Menu+M | Color / Grayscale (всё оттенками серого) / Mono (экран БК в 4 цветах как на чёрно-белом мониторе, 512 точек) |
| Reset | Menu+F12 | сброс машины (холодный сброс AZ) |

## Демо-софт ([sd/bk](sd/bk))

Набор дисков пакета AZBK из retro-tang-bk (MAXIOL и авторы программ):

| Файл | Что |
|---|---|
| `WRKANDOS2.IMG` | ANDOS 3.30, рабочий диск: оболочка, утилиты, БЕЙСИК, отладчики, `AY_TEST` (тест AY, GID). Диск AZ0 по умолчанию |
| `SNDTEST.IMG` | тот же диск и тесты звука и памяти retro-tang-bk: `SPKTEST` динамик, `AYTEST` оба AY, `AY714` AY через 177714, `COVTEST` Covox, `DMATEST` звуковой DMA, `MEMTEST` память AZ (7 МБ, клавиша останавливает) |
| `AZKV.BKD` | диск AZ: тесты блиттера `blttst*`, графические демо `gdemo*` |
| `GAMES1.IMG` | ANDOS с играми БК (Ниндзя, Шериф, Super War и другие) |
| `toolkit.img` | ANDOS с инструментами уровней Dangerous Dave (`NLAB`, `DAVEBL`, тайлы, анимации) |
| `MKDOS317.IMG` | системный диск MKDOS 3.17 |
| `rt11bk.DSK` | RT-11 для БК |
| `eeprom.dat` | настройки контроллера AZBK (выключен режим БК11, YM2149, Covox стерео, таймер 48 Гц) |

регистрации, кладётся в `/bk` и выбирается как AZ0.

## Ограничения

- Нет сети, снимка экрана (команда 044), RS-232, магнитофона.
- Файловые команды контроллера по имени (047, 050-055), каталог (003 / 013) и монтирование из программы
  (004 / 014) отвечают ошибкой: прошивка Karabas не даёт ядру файлов по имени. Образы выбираются в OSD.
- Часы, установленные программой (034), в часы платы не записываются.
- Процессор работает быстрее настоящего БК (BIOS показывает «6MHz»): задержки памяти БК не моделируются.
- Режим БК-0010 (ПЗУ есть) не проверялся.
- Запись на диск и в EEPROM на плате пока не проверялась.
